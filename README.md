# Marketplace Dataton: Прогноз прибыльности пользователей онлайн-магазина

## Описание проекта

**Кейс 4. Создание прогнозной модели для онлайн-магазина:**  
Цель проекта — предсказать прибыльность пользователя на основе истории покупок и возвратов.

**Компания:** Онлайн-магазин с широкой линейкой товаров и развитой системой доставки и возвратов.  
**Продукт:** Платформа e-commerce, которая стремится повысить прибыльность клиентской базы и снизить затраты на обслуживание возвратов.  

**Проблема:**  
Значительная часть клиентов генерирует убытки из-за частых возвратов и низкой маржинальности покупок. Это снижает общий показатель LTV (Lifetime Value) и искажает прогнозы финансового роста.

---

## Данные

В проекте используется датасет пользователей с информацией о покупках и возвратах:

- `user_id` — идентификатор пользователя  
- `platform_num` — количество устройств, с которых пользователь входил в личный кабинет  
- `first_login` — дата первого логина  
- `reg_dt` — дата регистрации  
- `browser` — предпочитаемый браузер пользователя  
- `first_buy` — дата первой покупки  
- `total_buy` — общий объем покупок на момент среза  
- `total_return` — общий объем возвратов на момент среза  
- `target` — отношение возвратов к покупкам в течение следующего месяца после даты среза  

> **Примечание:** Датасет хранится в папке `data/marketplace.csv`.
